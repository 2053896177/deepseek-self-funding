# 商业模式与变现路径

## 核心逻辑

```
6 元免费额度（种子）
    ↓ 调用 API 生成
数字产品（申论模板 / 英语模板 / 面试题库）
    ↓ 上架售卖
被动收入（9.9 元/份）
    ↓ 提现充值
更多 API 额度 → 生成更多产品 → 更多收入
```

## 为什么 DeepSeek 定价低是好事

DeepSeek flash 模型闲时输入只要 **0.02 元/百万 token**。
这意味着：
- 生成一套 1 万字的产品，成本约 0.05 元
- 6 元额度可以生成 **120 套以上**产品
- 每套卖 9.9 元，哪怕只卖出去 10 份，就有 99 元收入
- 99 元可以再生成 2000 套产品

**边际成本趋近于零，这是数字产品的最大优势。**

## 推荐产品品类（从易到难）

### 第一梯队：最快见效
1. **公考申论模板** - 考生刚需，付费意愿强
2. **专升本英语作文模板** - 专升本人群庞大
3. **网格员/事业单位面试题库** - 本地岗位竞争激烈

### 第二梯队：可以扩展
4. **教资考试笔记模板**
5. **行测图形推理秒杀技巧**
6. **简历模板 + 求职信模板**

### 第三梯队：长期被动收入
7. **Prompt 工程模板库**
8. **Excel 财务/记账模板**
9. **读书笔记 Notion 模板**

## 售卖平台对比

| 平台 | 手续费 | 提现门槛 | 适合产品 |
|---|---|---|---|
| 爱发电 | 5% | 极低 | 模板、电子书、数字产品 |
| 闲鱼 | 0 | 极低 | 虚拟资料、题库 |
| 小红书 | 0 | 需私域 | 引流 + 成交 |
| 淘宝虚拟 | 5% | 需店铺 | 规模化后 |

## 起步建议

1. **先做 1 套，上架，验证有人买**
   - 别一上来就生成 100 套
   - 先做一套申论模板，挂爱发电
   - 看看有没有人下单，再决定要不要扩大

2. **小红书引流**
   - 发笔记：「申论大作文开头我就背这 3 套」
   - 配图用模板截图
   - 评论区引导私信

3. **收入优先回流充值**
   - 第一笔收入先充回 DeepSeek
   - 用赚来的额度生成下一套产品
   - 逐步扩大产品矩阵

## 风险提示

- **合规**：不要卖真题答案、不要卖涉及内部资料的内容
- **质量**：AI 生成的内容一定要人工审核一遍，改改错别字和逻辑
- **重复**：批量生成时调大 temperature，避免每套都一模一样
- **平台规则**：闲鱼对虚拟商品有管控，注意别违规
